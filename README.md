# michaelrockman.com site

Plain HTML and CSS, no build step, no tracking, no backend.

## Preview on your Mac

Open Terminal, then paste this line and press Return:

```bash
cd "/Users/mrockman/Library/CloudStorage/OneDrive-Personal/PSTP/Post-Doc/Data/_PatchClampAnalysis/michaelrockman-site" && python3 -m http.server 8000
```

Then open http://localhost:8000 in your browser. Press Control-C in Terminal to stop the preview.
